# 首页与历史统计

- 左侧五个并列一级菜单：首页、历史统计、键盘统计、鼠标统计、手柄统计。手柄页面暂为占位页。
- 所有时间选择首次进入默认今天，各页面分别记住后续选择。
- 首页只保留按键排行与软件点击次数排行两张卡片，水平间距 36 像素。
- 首页全部统计均为本地日期的今天（含尚未保存的内存计数），按次数降序。跨午夜自动重新查询。
- 按键排行标题行内提供软件、设备类型组合筛选，默认全部软件和全部设备；占比以当前筛选结果为分母。不显示标题下说明或“当前筛选共……”文字。
- 软件点击次数排行标题行内提供独立设备类型筛选，默认全部设备。键盘、手柄按按下次数统计；鼠标计左、右、中和两个侧键，不包含滚轮。右侧排行不受按键排行的软件及设备筛选影响，导出全部 CSV 也保持完整范围。不显示软件排行标题下的说明小字。
- 首页标题右侧显示“鼠标输入 + 键盘输入 + 手柄输入 = 今日输入次数”。三个分项数字下方标明设备类型，合计使用更大字号。今日按本地日历日期计算，独立于排行筛选，包含尚未落盘的内存计数；鼠标输入总数沿用采集统计口径，包括滚轮刻度。跨本地午夜时重新统计今日数据，即使没有新输入也会刷新。
- 软件图标继续使用运行目录缓存。没有点击记录时显示明确的空状态。
- 新采集的滚轮输入采用全局 1000 毫秒限频，每个窗口最多计一次，方向取首次有效滚动；所有鼠标共用限频窗口。今日公式、按键排行与活跃度均使用限频后的次数。历史已保存的旧刻度计数不重新换算。
- 软件名称实时读取当前可见窗口标题，无标题时使用进程名，不缓存或保存标题；界面可见时约每秒重新提取一次，即使没有新输入也会更新。一次刷新共用本次窗口快照，同一软件标题变化不拆分计数。部署时删除旧的 `cache/app-names.json`，图标缓存保留。
- 对 RuntimeBroker、ApplicationFrameHost 宿主尝试查找实际内容子窗口的进程；找不到时仍使用宿主进程。历史宿主计数不重新分配，本次未实机验证便笺。
- 页面容器、滚动视口及卡片之间的空白统一使用主背景色。
- 历史统计顶部时间范围控制两张排行和活动图。支持今天、昨天、最近一周（含今天的 7 个日历日）、一月（到明日零点为止的最近一个月）、全部时间及自定义范围；全部时间位于自定义范围之前。全部时间按现有记录的首末本地日期计算图表范围，无数据时使用今天。
- 自定义起止时间精确到秒，含起点、不含终点；本地时间转换为 UTC 秒查询。包含尚未落盘的数据，保存后不会重复增加。
- 历史按键排行提供软件和设备类型筛选，软件排行提供独立设备类型筛选。
- 时间活跃度提供独立的软件和设备类型筛选，不受排行筛选影响；活动次数包含滚轮刻度。缩放条向左细化、向右概览，最细时间块随范围调整：一天约 1 小时，一周半天，一个月一天，更长范围按约 31 个最细时间块计算；最粗可合并整个范围。分钟聚合可在内存中重新合并，不因拖动反复查询数据库。支持水平滚动、悬停查看时段及次数。时间选择下方和活动图下方不显示描述小字。
- 时间活跃度下方不再显示活跃时段列表。
- 首页底部仅显示“最近一次保存时间为 yyyy-MM-dd HH:mm:ss”；暂无记录时显示尚未保存。错误单独显示在提示栏。
- 最近保存时间写入运行目录 `config/last-save.json`，下次启动继续显示。
- 设置、立即保存、导出全部 CSV、清空历史保留在侧栏；CSV 仍导出全部设备的输入统计。
- 切换到占位页面停止排行查询，后台采集继续；返回首页重新查询。

当前存储版本为 v4；本次按明确要求只重置旧鼠标计数，保留键盘、手柄记录。仅构建发布，未执行自动测试、UI 测试或启动新版进行验证。

## 键盘统计

- 复用历史统计的时间选择，包括今天、昨天、最近一周、一月、全部时间、自定义范围，采用含起点、不含终点的区间。
- 独立的软件筛选，只查询键盘控制项，包含尚未落盘的数据。实时窗口标题与图标沿用现有规则。
- 绘制 ANSI 标准 104 键全尺寸布局，包含主键区、功能键、编辑键、方向键和小键盘；以物理扫描码和 E0/E1 标志映射，不依赖键位显示名称。
- 左右 Ctrl、Alt、Shift、Win、主 Enter 和小键盘 Enter 分开。小键盘数字与主区数字分开，不随 Num Lock 显示名称变化而混计。
- 每键占比使用当前时间及软件筛选下的键盘总次数作为分母；104 键之外的扩展控制项仍保留在原统计中，不强行映射。
- 底色采用冷紫、蓝、青、绿、黄、红渐变，按当前筛选内各键占比相对最高占比映射；零次数保持冷色，无数据时全部保持冷色。悬停仅显示按键名称、次数和实际占比，不显示物理代码。
- 窗口缩小时键盘按比例绘制，必要时支持滚动；不添加描述小字。

## 鼠标统计

- 复用时间选择，首次进入默认今天；按所选范围查询全部鼠标、全部软件。
- 按屏幕及其位置、分辨率配置展示点击热力图；可选择左键、右键或左右键（默认），中键、侧键和滚轮不参与该热力图，原始计数仍保留。
- 右侧表格分别以左右键总次数、滚轮上下总次数、四项合计次数为分母，显示各自占比；零次数显示 0%。滚轮继续使用全局 1000 毫秒限频。
- 点击任一热力图，在该屏幕对应的当前显示器上全屏显示，按原始屏幕内像素坐标绘制点击点；右上角 X 或 Esc 退出。记录屏幕不再连接时使用主屏显示，分辨率不同则等比例显示。
- 预览不绘制显示器底座。全屏右上角提供透明度滑条：0% 不透明、100% 完全透明，默认 0%；控制条和 X 不随热力图透明度变化。
- 预览及全屏均可调整聚合半径（1–200 物理像素，默认 24）。按次数优先选取固定中心点，将半径内点击聚合为次数加权中心，再进行高斯平滑；不修改数据库坐标。筛选与聚合只在内存中完成，不重新查询数据库。全屏默认显示聚合点，可切换“原始点”查看当前按键筛选下的精确坐标；旁侧占比表仍统计所选时段的全部左右键及滚轮。
- 只存鼠标操作时的位置聚合，不记录指针轨迹，不截图；新输入实时参与视图，仍按配置间隔批量写入 SQLite。
