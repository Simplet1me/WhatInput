# 时间活跃度分组柱状图

- 历史统计时间活跃度使用按小时、按天、按周、按月、按年选项，默认按小时，替代原来的细化／概览缩放条。
- 以本地日历边界分组：整点、本地零点、周一零点、每月一日、每年一月一日。夏令时按本地时区换算；首尾分组只包含查询范围，区间含起点、不含终点。
- 每组四条并列柱，固定从左到右为总和、鼠标、键盘、手柄。总和等于三设备之和，四个系列使用不同颜色。
- 图例位于图表下方，点击可独立隐藏或恢复系列。隐藏不改写数据，不改变总和的定义，柱子保留原来的系列位置；纵轴按可见系列最大值计算整齐的四等分刻度，从零开始。
- 横轴按真实时间间隔绘制，包含起止时刻标签。无活动时段保留时间空白；时间轴适应卡片宽度，不允许横向滚动。悬停柱子显示裁剪后的分组起止时间、系列名称和次数。
- 原软件筛选继续生效。设备显示由图例取代旧的设备筛选；分组及图例不影响其他排行。
- 继续包含未保存的内存输入；组合次数、鼠标移动距离不计入活动输入，摇杆方向次数按原手柄输入口径计入。
- 工作线程保存每分钟、每设备的内存汇总，改变分组时重新合并日历分组，无需额外查询数据库。分组只改变视图，存储格式和数据库版本保持不变，不删除历史数据。
- 绘图代码位于 src/ui/history/activity_chart.*，日历边界函数位于 src/engine/activity_time.h。

本次仅构建、部署，未执行自动测试、图表交互测试或启动验证。
- 时间活跃度位于历史排行榜上方，筛选项靠左；卡片高度随可见区域的 75% 自适应，范围 420–720 像素，图表无内部滚动，完整时间范围压入当前宽度。页面仍可纵向滚动查看下方排行榜。

- 页面由布局自动计算所有可见卡片的总高度，替代固定页面最小高度；切换页面和调整窗口尺寸时同步更新滚动范围，底部保留 16 像素留白。
