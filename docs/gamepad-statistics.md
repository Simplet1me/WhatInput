# 手柄统计

- 使用 XInput 轮询，多个手柄合并排行与热力图。当前前台软件作为输入归属；继续支持已连接约 8 毫秒轮询和断开插槽低频探测。
- 左右摇杆各自归一化 X、Y：负半轴除以 32768，正半轴除以 32767。半径 sqrt(x²+y²) > 0.1 时视为活动。
- 每个手柄每 500 毫秒采样一次；活动的摇杆各累计一次，持续活动约每秒两次。不按轮询次数累计，也不补算休眠或调度延误的采样。中途短于采样间隔的运动可能不被计入。
- 左摇杆移动 pad:LS_MOVE:0–15、右摇杆移动 pad:RS_MOVE:0–15 与 L3/R3 按压为独立控制项；摇杆移动纳入手柄输入总数、按键排行、软件排行和活跃度。
- 重连、唤醒后先建立状态基线，500 毫秒后重新采样摇杆；普通按钮仍只统计松开到按下，重连时已按住的按钮不增加一次点击。
- 手柄统计菜单提供共用时间选择（默认今天）与独立软件筛选，含起点、不含终点，包含尚未保存的数据。
- XInput 布局热力图覆盖 ABXY、十字键、LB/RB、LT/RT、Back/Start、L3/R3 和左右摇杆移动。摇杆外圈的 16 个扇区表示移动方向，内圈表示按压。底色根据筛选范围中各项次数相对最大值映射；悬停仅显示名称、次数、占比。
- 不保存摇杆方向或位置轨迹，仅保存活动次数。

本次未获测试许可，仅完成构建和部署；手柄硬件与阈值行为尚未实测。
## 十六方向

- 以上为 0°，顺时针每 22.5° 一个方向；扇区以方向角为中心，左右各覆盖 11.25°。刚好落在交界时归入顺时针一侧，0° 附近跨越 360° 正常衔接。
- 方向依次为上、上偏右、右上、右偏上、右、右偏下、右下、下偏右、下、下偏左、左下、左偏下、左、左偏上、左上、上偏左。
- 仍每 500 毫秒对左右摇杆分别采样；半径大于 0.1 才给当前方向加一次，不额外累计摇杆移动总项，不因方向切换额外增加输入。
- 方向分项直接参与通用排行、软件统计和活动统计；软件及时间筛选同步作用于热力图。扇区颜色与普通按钮共用最大次数标尺，悬停占比以当前筛选范围的手柄总输入为分母。
- 存储版本升为 v6，按工作区规则删除旧库重建，不将旧的无方向摇杆记录分摊或迁移。
- 本次仅构建、部署，未运行自动测试、界面验证或手柄实测。
