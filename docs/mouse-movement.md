# 鼠标移动统计（米制）

- 独立一级菜单，默认今天，复用昨天、最近一周、一月、全部时间和自定义范围。
- 使用 Raw Input 相对移动量，逐个报告计算 sqrt(dx²+dy²)，按 米 = 原始计数 / DPI × 0.0254 换算；不受 Windows 指针速度、加速、屏幕分辨率影响。结果是基于传感器标称 DPI 的估算，曲线在单个报告内近似为直线。
- 页面直接提供鼠标 DPI 和应用 DPI 按钮，默认 2000；允许 50–100000，保存到运行目录 config/mouse-distance.json。多个鼠标共用此设置，不同 DPI 的鼠标需改成匹配值。修改仅影响之后采集的数据，历史米数不重新换算。
- 按采集时鼠标目标窗口的软件归属累计，沿用全屏识别和 Windows 系统分类。只支持相对移动型鼠标；触屏、数位板等绝对坐标报告不换算为实际桌面距离。
- 内存按 UTC 分钟、软件聚合；内部整数单位为纳米，独立表 mouse_movement(minute_utc, app_id, distance_nanometers)，前两列为主键。没有逐次移动记录、方向、坐标或轨迹。
- 使用已有保存周期（默认 60 秒）、退出提交和可重试批次事务。未保存距离实时参与查询，保存后不重复累计。
- 页面显示米制总距离、软件距离排行及占比，软件显示实时窗口标题和图标。自定义范围精确到分钟，含起点、不含终点。
- 距离不参与按键次数、活跃度和点击热力图，按键 CSV 不包含距离。
- 当前存储格式为 v7。按 AGENTS.md 正常退出后删除运行目录旧数据库及 WAL、SHM，不进行历史迁移。

本次仅构建与部署，未执行启动、鼠标距离实测或性能测量。
