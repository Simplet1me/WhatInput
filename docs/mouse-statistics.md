# 鼠标位置统计（v4）

本次用户明确要求保留键盘和手柄数据，仅允许丢弃鼠标数据，因此此升级不采用工作区通常的整库删除规则。

## 数据流

- 在实际记录鼠标操作时读取物理光标位置，确定所在屏幕；不处理鼠标移动消息的位置轨迹。
- 保存屏幕标识、显示设备名称、桌面原点、宽高、屏幕内像素坐标。桌面原点支持副屏的负坐标。
- 内存键增加可选鼠标位置；键盘、手柄不携带位置。同秒、同软件、同控制项、同屏幕配置及同坐标合并次数，无事件顺序。
- `counts` 保留通用按键聚合。`mouse_screens` 保存屏幕配置，`mouse_positions` 以 UTC 秒、软件、控制项、屏幕配置、x、y 为主键保存位置次数。
- 通用计数、坐标次数和批次标记在同一事务提交，重试不会重复累计。保存间隔、退出前提交、失败保留内存逻辑沿用现有实现。
- 查询鼠标页时才读取位置表；已提交位置与待提交位置只合并一次。其他页面继续查询通用聚合。

## 保留与边界

- v3 首次打开时通过事务清除 `devices.type='mouse'` 对应的旧计数，保留键盘、手柄、软件和控制项元数据，建立位置表后将 `user_version` 设为 4。事务失败时回滚；v4 再次启动不会再次清除鼠标记录。
- 此次部署不删除数据库、WAL 或 SHM；升级在用户首次启动新版时执行。
- 未能获得光标或屏幕信息时仍保留普通计数，但不能生成该次热力点。
- 热力图可筛选左键、右键、左右键，默认左右键。视图查询保留按键类型，前端筛选不改变记录或重新查库。占比表独立统计左键、右键、滚轮上、滚轮下，滚轮沿用每 1000 毫秒最多一次。
- 直接将原始坐标按次数双线性投到密度栅格；使用三次归一化盒式卷积近似高斯 KDE，镜像边界处理保留边缘点击。平滑值表示近似影响半径（1–200 物理像素，默认 24），标准差使用该值的三分之一。旧版将 UI 半径直接当作标准差，导致影响范围明显偏大，此处已收紧。原始坐标不被修改。
- 计算栅格保持屏幕宽高比，最大 2560×1600，输出单位为每物理像素的点击密度。所有屏幕共用最大密度标尺，不再每屏单独归一化。颜色支持线性与对数映射，强度范围 25%–400%，默认对数、100%；强度只影响着色，不改变次数或密度。
- 在密度层生成分辨率金字塔，再分别使用同一颜色标尺着色，避免多次混合 RGB 颜色造成模糊和错误中间色。总览按显示尺寸和 DPI 选图层，全屏使用高分辨率层；启用“原始点”可叠加实际坐标。
- 软件筛选在存储线程中同时筛选通用计数与坐标聚合，热力图、占比表同步变化。切换时间或软件时取消旧渲染，避免旧软件热力图覆盖新结果；不改变数据库格式或历史数据。
- 全屏初始沿用总览的共享渲染结果；改变参数时以打开时的全部屏幕数据快照重新计算，仍跨屏共享标尺，不单独拉伸当前屏幕颜色。没有截图，不移动系统光标，也不回放点击。
- KDE 与图像生成由独立工作线程完成，等待队列仅保留最新请求，旧筛选结果不会覆盖新筛选。可复用未变化的密度与图像；关闭、最小化或切走鼠标页会取消任务并释放缓存。这里缓存仅为内存渲染数据，不是持久化文件。
- 屏幕接口标识用于关联记录，配置变化以新的屏幕配置保存；历史屏幕断开时在主屏等比例显示，不能保证当前屏幕更换后还能按原物理尺寸显示。
- 原 CSV 导出仍为通用计数汇总，不是坐标明细导出。

## 本次验证状态

仅完成完整 Release 构建、部署；未运行启动、数据库保留、坐标、DPI、多屏或全屏交互测试。键盘／手柄保留及首次鼠标重置逻辑尚待获准后实测，不能将编译成功视为运行验证。
