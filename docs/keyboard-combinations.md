# 组合按键统计

- 独立一级菜单“组合按键统计”，默认今天，复用共用时间范围，支持软件筛选和按次数降序排行。占比以当前筛选范围内的组合次数为分母。
- 第一版识别 Ctrl、Alt、Shift、Win 修饰键与一个非修饰键组合。按下非修饰键的有效边沿时，为当前完整修饰键集合与该键记录一次，例如 Ctrl+C、Ctrl+Shift+C、Alt+Tab。
- 固定修饰键顺序为 Ctrl、Alt、Shift、Win，左右侧在组合中合并显示；普通键使用物理扫描码与扩展标志识别，保留主 Enter 与小键盘 Enter 等区别。组合身份不依赖可变化的显示名称。
- Ctrl+C：普通键表 Ctrl 和 C 各加一，独立组合表 Ctrl+C 加一；组合不重复计入首页输入总次数、普通键排行、软件点击排行或活动图。
- 按住 Ctrl 连续点 C 两次产生两次组合；C 长按自动重复不增加组合。仅按修饰键、无修饰键的多键重叠、先按普通键再补修饰键不生成组合；不识别先后输入的快捷键序列。
- 多把键盘的修饰键状态共同参与识别。每个设备的按下边沿独立；拔出设备立即移除其修饰键，休眠与唤醒清除组合修饰键状态，避免沿用过期状态。
- 使用系统实际上报的键位；AltGr 若被系统拆成 Ctrl+Alt，则按实际上报的 Ctrl+Alt 统计，不推断用户意图。
- 软件归属为组合触发时的前台软件。记录 UTC 秒、组合身份、名称、软件和聚合次数；不保存输入文本、触发顺序或逐次事件。
- 独立表 keyboard_combinations(second_utc,identity,name,app_id,press_count)，主键为秒、组合身份、软件。和普通计数共享同一事务与批次标记，重试不重复累计；内存增量参与实时排行，提交后不重复显示。
- 含起点、不含终点的时间区间精确到秒；全部时间涵盖组合表首末记录，软件名称沿用实时窗口标题和图标。原按键 CSV 不包含独立组合数据。
- 数据库版本 v7，部署前正常退出程序并删除运行目录旧数据库、WAL、SHM，新版重建，不迁移旧数据。
